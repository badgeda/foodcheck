FOODCHECK – ΟΔΗΓΙΕΣ ΑΝΕΒΑΣΜΑΤΟΣ

1. Αποσυμπίεσε το ZIP στον υπολογιστή.
2. Συνδέσου στο https://github.com ή δημιούργησε δωρεάν λογαριασμό.
3. Πάτησε το + επάνω δεξιά και μετά New repository.
4. Όνομα: foodcheck. Επίλεξε Public και πάτησε Create repository.
5. Πάτησε “uploading an existing file”.
6. Σύρε ΟΛΑ τα αρχεία και τους φακέλους του αποσυμπιεσμένου FoodCheck (index.html, app.js, sw.js, manifest.webmanifest, icon.svg).
7. Πάτησε Commit changes.
8. Άνοιξε Settings → Pages.
9. Στο Build and deployment επίλεξε Deploy from a branch.
10. Branch: main και folder: /(root). Πάτησε Save.
11. Περίμενε 1–3 λεπτά. Η διεύθυνση θα είναι:
    https://ΤΟ-ΟΝΟΜΑ-ΣΟΥ.github.io/foodcheck/

ΕΓΚΑΤΑΣΤΑΣΗ ΣΤΟ SAMSUNG (Samsung Internet)
1. Άνοιξε τη διεύθυνση GitHub Pages στο Samsung Internet.
2. Πάτησε το μενού ☰.
3. Επίλεξε “Προσθήκη σε” → “Αρχική οθόνη”.
4. Πάτησε “Προσθήκη”.
5. Το εικονίδιο FoodCheck θα εμφανιστεί στην αρχική οθόνη.

ΣΗΜΑΝΤΙΚΑ
- Η εφαρμογή είναι δωρεάν και δεν χρειάζεται Play Store.
- Η αναζήτηση barcode χρησιμοποιεί το Open Food Facts και χρειάζεται σύνδεση στο διαδίκτυο.
- Η κάμερα και η εγκατάσταση PWA απαιτούν HTTPS· το GitHub Pages το παρέχει.
- Η αυτόματη σάρωση εξαρτάται από την υποστήριξη BarcodeDetector του browser. Αν δεν υποστηρίζεται, πληκτρολόγησε το barcode.
- Η αξιολόγηση είναι ενδεικτική, όχι ιατρική οδηγία. Τα δεδομένα της βάσης μπορεί να λείπουν ή να είναι λανθασμένα.
